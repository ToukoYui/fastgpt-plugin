# 表格数据提取（spreadsheet-extractor）

上传 csv / xls / xlsx 表格文件，将每一行按字段输出为 JSON 对象，可选列名到输出字段名的映射。

## 使用方式

1. 在节点中上传表格文件（支持 csv、xls、xlsx）。
2. 可选：在「列名-输出字段映射(JSON)」中填写 `{"原列名":"输出字段"}`，支持多列。为空则输出全部列，使用原表头作为键名。
3. 节点输出 `result` 为对象数组，每个对象代表一行数据。

## 注意事项

- 会自动清洗表头空白字符；若映射中的列名在表格中不存在会返回错误。
- 空值会输出为 `null`。
